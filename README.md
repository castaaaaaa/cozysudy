# 🍅 FocusVault

A cozy, single-page Pomodoro web application designed for focused study sessions with friends. I built this to make studying less boring by adding real-time multiplayer features and a gamified coin economy.

## ✨ Features
* **Real-Time Study Rooms:** Create a room, share the code, and study together. Usernames and timers are synced perfectly using Supabase Realtime.
* **Coin Economy:** Earn coins for every minute of deep focus.
* **Cozy Background Shop:** Spend your hard-earned coins to unlock atmospheric backgrounds (like rainy nights or cozy fireplaces) that change the entire vibe of the room.
* **Zero Reloads:** Fully built as a Single Page Application (SPA) with smooth state transitions.

## 🛠️ Tech Stack
* **Frontend:** React.js, Vite, Tailwind CSS
* **Backend / Database:** Supabase (Realtime & Presence)
